# Go Implementation of [HiddenWG](https://github.com/mustaddon/hiddenwg/)

This repository is a [fork](https://github.com/WireGuard/wireguard-go) that adds obfuscation to the standard [WireGuard](https://www.wireguard.com/) protocol.

## Building

This requires an installation of the latest version of [Go](https://go.dev/).

```
$ git clone https://github.com/mustaddon/hiddenwg-go
$ cd hiddenwg-go
$ make
```
